# Project Governance & Roles

CairnJS is an open-source, merit-based project.

---

## Roles

### Maintainers
Lead architects responsible for repository direction, security releases, and NPM deployment.

### Core Collaborators
Active contributors with write access, review responsibilities, and issue management.

### Contributors
Anyone who submits issues, pull requests, examples, or documentation improvements.

---

## RFC Decision Process

For major new features (e.g. state management paradigms, new WASM kernels), create an RFC discussion on GitHub. Discussions remain open for at least 7 days before final maintainer consensus.
