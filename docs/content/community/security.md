# Security Policy & Responsible Disclosure

CairnJS prioritizes the safety and security of all developers and production applications built with our framework.

---

## Supported Versions

| Version | Status |
|---|---|
| `1.2.x` | ✅ Full Security Support |
| `1.1.x` | ✅ Critical Fixes |
| `< 1.1.0` | ❌ End of Life |

---

## Reporting Vulnerabilities

Please do not open public issues for security vulnerabilities.

1. **Email**: Send detailed reproduction steps to **eldrexdelosreyesbula@gmail.com** with `[SECURITY]` in the subject.
2. **GitHub Advisory**: Submit via repository Security Advisories.

We commit to acknowledging all reports within **48 hours** and delivering verified patches within **14 business days**.
