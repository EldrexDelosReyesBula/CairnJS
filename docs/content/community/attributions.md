# Tool & Library Attributions

CairnJS is engineered from the ground up as a zero-dependency reactive web framework. While the core runtime carries zero external npm runtime dependencies, we would like to give full credit and heartfelt appreciation to the pioneering tools, open-source libraries, and platforms that power our documentation, build systems, development workflow, and ecosystem inspiration.

---

## 🛠️ Documentation & Playground Tooling

### 1. [Monaco Editor](https://microsoft.github.io/monaco-editor/)
- **Creator**: Microsoft Corporation
- **License**: MIT
- **Role**: Powers the rich in-browser code editor in the CairnJS Live Playground with real-time IntelliSense, syntax validation, and split-screen preview.

### 2. [Marked.js](https://marked.js.org/)
- **Creator**: Christopher Jeffrey & Marked.js contributors
- **License**: MIT
- **Role**: Fast, lightweight Markdown parser and compiler for the official CairnJS documentation site.

### 3. [Prism.js](https://prismjs.com/)
- **Creator**: Lea Verou & Prism.js community
- **License**: MIT
- **Role**: Lightweight, extensible syntax highlighter powering code snippets across the documentation guides.

### 4. [Font Awesome](https://fontawesome.com/)
- **Creator**: Fonticons, Inc.
- **License**: Icons: CC BY 4.0, Fonts: SIL OFL 1.1, Code: MIT
- **Role**: Crisp iconography across navigation bars, sidebar guides, feature pillars, and control widgets.

## ⚡ Core Engine & Runtime Inspiration

### 1. [WebAssembly (WASM)](https://webassembly.org/) & [Rust](https://www.rust-lang.org/)
- High-performance shared-memory linear buffer architecture enabling zero-traffic synchronization between JavaScript and WASM state kernels.

### 2. [WebGL & Canvas 2D](https://www.khronos.org/webgl/)
- Khronos Group native hardware acceleration standards utilized by `src/canvas3d.js` and `src/canvas2d.js` for zero-dependency 60fps 3D scene rendering and particle kinematics.
